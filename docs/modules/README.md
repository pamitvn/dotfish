# Module usage guides

One page per Module, for people who ran the Installer. Each guide covers what
the Module changes in your shell, how to use it, and how to tweak or remove it.
Pick Modules in the `dotfish` picker or with `dotfish --modules a,b,c`.

| Module | What it adds | Default |
|---|---|:---:|
| [eza](eza.md) | Replace `ls` with eza (icons, git, tree) | ✓ |
| [gh](gh.md) | `GITHUB_PERSONAL_ACCESS_TOKEN` from the gh keyring | ✓ |
| [bat](bat.md) | bat as a nicer `cat` and for man pages | ✓ |
| [ugrep](ugrep.md) | Replace the grep family with ugrep | ✓ |
| [rustup](rustup.md) | Rust toolchain via rustup (cargo env) | ✓ |
| [docker](docker.md) | Docker helpers and completions | ✓ |
| [php-stack](php-stack.md) | Docker-aware `artisan`/`composer`/vendor-bin wrappers | ✓ |
| [pnpm](pnpm.md) | pnpm on `PATH`; enforce it over npm/yarn/bun | ✓ |
| [starship](starship.md) | Starship cross-shell prompt | ✓ |
| [asdf](asdf.md) | asdf version manager | ✓ |
| [fastfetch](fastfetch.md) | Fastfetch greeting (loads last) | ✓ |
